# ADR-001 接线路线优先

- **状态：** 已确定
- **日期：** 2026-11-10
- **提出人：** 产品负责人
- **确认人：** 产品负责人

## 背景

电贝斯最低音是 41 Hz。手机内置麦克风在 60 Hz 以下灵敏度下降，而且会同时录到房间、音箱和伴奏。调研报告收集的用户反馈里，竞品在“麦克风加音箱”条件下有低音识别失败的案例。

## 决定

拾音以接线为主：贝斯 → 音频接口 → iPhone（USB-C）。所有设计、测试集和验收标准都按接线干声来定。麦克风拾音降为以后的可选项。

## 理由

- 干声信号干净、可重复，41 Hz 基频完整，没有伴奏串音。
- 判定出了问题时，能分清是演奏问题还是接入问题。
- 同一个接口还能在 Windows 上录测试集。

## 后果

- 用户需要买一个音频接口和一副有线耳机。选型标准见 `../01_FEASIBILITY.md` Q1。
- App 需要一个接入体检流程。
- 输入层要做抽象，给麦克风和 MIDI 留口子（ADR-007）。

## 什么时候重新审视

不重新审视主路线。麦克风路线作为附加选项，在阶段 3 以后由日志决定是否加入。
