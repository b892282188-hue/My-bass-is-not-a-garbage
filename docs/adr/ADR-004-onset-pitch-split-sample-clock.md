# ADR-004 起音和音高分开检测；评分使用采样时间戳

- **状态：** 提议中
- **日期：** 2026-11-10
- **提出人：** 评审员（Claude）
- **确认人：** 待产品负责人确认

## 背景

同一个音连续弹时，音高轨迹不变，只看音高数不出弹了几次。最低音的音高确认需要 50 到 80 ms，但起音在几毫秒内就能定位。

## 提议

1. 起音检测和音高检测是两个独立模块，各自输出带采样时间戳的事件，由对齐模块合并。
2. 节奏评分只用起音时间戳。音高结论可以晚到，再补到对应的音符上。
3. 全系统只有一个时钟：音频硬件的采样时钟。伴奏按采样时刻调度；谱面时间由速度表换算；屏幕播放头每一帧由当前时间现算。不用定时器，不用系统墙上时间。
4. “评分时间戳准确度”和“反馈显示及时度”是两个独立指标，分别验收。
5. 界面做两段式反馈：先显示起音和早晚，再显示音高结论。
6. 每种“设备加路线”保存一个校准值，由回环测试得到。

## 理由

见 `../01_FEASIBILITY.md` Q2 的 2.5、2.7 和 Q3 的 3.3。

## 后果

- 最低音的音高反馈会比起音提示晚几十毫秒，这是有意的设计。
- 需要一个回环校准流程（实验 S5）。

## 什么时候确认

实验 S4 和 S5 完成后。
