# ADR-006 监听默认用接口硬件直接监听加有线耳机；第一版不做软件监听，不支持蓝牙耳机

- **状态：** 已确定
- **日期：** 2026-11-10
- **提出人：** 评审员（Claude）
- **确认人：** 产品负责人（2026-11-10）

## 背景

用户需要同时听到自己的琴声和伴奏。琴声经过软件再出来会有延迟。负责人有 AirPods Pro 3，原设想是用它听伴奏。

## 决定

1. 默认方案：有线耳机插在接口上，打开接口的直接监听。琴声在接口内部直接到耳机，不经过手机。
2. 接口同时是 iPhone 的输出设备，伴奏和节拍器从同一个耳机口出来。
3. 第一版不做软件监听：App 不把输入信号送回输出。
4. 第一版不支持蓝牙耳机。以后如果要加，先做实验 S7，并且该模式下的节奏评分标为“参考”。

## 理由

- 琴声零软件延迟。
- 输入和输出在同一个硬件时钟上，没有漂移，延迟小而且稳定，可以用回环测试精确校准。
- 戴着 AirPods 听不到接口耳机口里的琴声，还得另开音箱。蓝牙延迟大而且每次连接可能不同。

## 后果

- 需要一副有线耳机（负责人已有）。
- 不能在 App 里给琴声加效果或音箱模拟。想要这些，用接口或外接设备。
- AirPods 暂时用不上。

## 备选

- AirPods 听伴奏加音箱听琴声：设备多，需要校准流程，评分可信度下降。作为阶段 3 以后的候选。
