# ADR-009 第一版算法：起音用能量与谱通量，音高用 MPM 类周期检测；实时路径不用神经网络

- **状态：** 提议中
- **日期：** 2026-11-10
- **提出人：** 评审员（Claude）
- **确认人：** 待产品负责人确认

## 背景

输入是接口送来的单声道干声，以单音为主，谱面已知。候选有 YIN、MPM、Cycfi Q 的 BACF、pYIN、神经网络。

## 提议

1. 起音检测：宽带能量上升加高频段瞬态（谱通量），带最小间隔。
2. 音高判定：MPM（归一化平方差函数）一类的时域周期检测，按 ADR-003 的验证模式使用，用它的清晰度作为置信度的起点。
3. Cycfi Q 的 BACF（MIT 许可）作为对照候选。实验 S2 用同一批录音比较 YIN、MPM、BACF，按数据决定最终选哪一个。
4. pYIN 和神经网络只在离线使用，用来给录音生成建议标签。
5. 第一版只支持四弦标准调弦。

## 理由

- 干净的单音信号上，时域周期法已经够用。
- 需要可解释的置信度来划“没听清”的界线。
- 算法简单，才能靠录音测试来保证正确，出了错才有办法诊断。
- 神经网络的输入窗口长、移植成本高、出错难解释。

## 后果

- 最低音 E1 的音高确认预计需要 50 到 80 ms，这接近物理下限。
- 五弦、降调需要以后重新评估最低频率和窗口。

## 什么时候确认

实验 S2 完成后。如果三个候选都达不到关卡 G1，再评估其他方法并重写本条。
