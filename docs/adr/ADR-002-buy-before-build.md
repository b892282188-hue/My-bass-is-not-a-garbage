# ADR-002 先买后造：阶段 0 不写应用代码

- **状态：** 提议中
- **日期：** 2026-11-10
- **提出人：** 评审员（Claude）
- **确认人：** 待产品负责人确认

## 背景

负责人是零基础。现在既不知道真正的痛点是什么，也不知道现成 App 接上接口后到底行不行。项目的头号风险是造工具成了逃避练琴的理由。

## 提议

阶段 0 不写应用代码。用一套成熟课程学琴，同时用现成的互动 App 接上接口练习，积累踩坑日志、竞品实测和自己的录音。

自己的 App 在同时满足以下三条之后才开始出现：

1. 至少 20 次有日志的练习，跨度至少 4 周。
2. 竞品实测完成，日志里有一个反复出现、现成工具解决不了的痛点。
3. 离线算法在自己的录音上通过关卡 G1。

第一个版本只解决日志里最痛的那一个问题。

## 理由

- 零基础阶段最需要的是正确的入门引导，现成课程已经做得很好。
- 没有真实痛点就动工，做出来的多半是想象中的需求。
- 竞品实测和录音，是自研算法以后必须用到的基准和测试集，早晚都要做。

## 后果

- 短期内手机上不会有自己的 App，最多有一个诊断用的探针程序。
- 需要订阅或试用一到两个现成 App。
- 可能的结局之一是发现现成工具够用，不再自研。这个结局是可以接受的。

## 备选

- 现在就开始做 App：能更早看到成品，但违背“痛点驱动”，并且会占用入门期最宝贵的练琴时间。不建议。
