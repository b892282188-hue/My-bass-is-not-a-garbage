# 冷启动入口

任何人或 agent 第一次接手这个项目，从这里开始读。

## 项目是什么

一个和使用者一起成长的私人贝斯学习工具。产品负责人是零基础的贝斯初学者，也是唯一的用户。他一边学琴一边记录踩的坑，由这些真实的坑来推动工具一点点成型。短期内不发布、不商业化。

一页版的定位在 [00_BRIEF.md](00_BRIEF.md)。

## 读这些文档时要知道的三件事

1. **事实、推测、判断是分开标的。** 标着“推测”的数字（尤其是延迟预算）还没有在真机上测过，每一条都对应 02 里的一个实验。实验做完后，用结果直接替换原文。
2. **调研报告有两个已知问题：** 它高估了竞品的拾音能力，并且把接线路线当成了配角。本套文档已经按负责人的意见纠正，引用报告时以本套文档为准。
3. **文档只描述当前状态。** 改了就直接改，历史写进 CHANGELOG。

## 三句话版本的方案

- **怎么接：** 贝斯接一个带乐器输入和直接监听的入门级 USB-C 音频接口，接口接 iPhone，有线耳机插在接口上，琴声和伴奏都从这里听。
- **怎么判：** 起音和音高分开检测。节奏看起音时间戳，音高用周期检测去“验证”谱面上的音，拿不准就说没听清，判错必须有证据。
- **怎么推进：** 先买现成的课程和 App 开始学，记日志、测竞品、攒录音；算法先在 Windows 上用自己的录音离线做到达标；最后才做 iOS，并且只解决日志里最痛的一个问题。
